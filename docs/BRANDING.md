# MoonWitness — Brand and Repository Identity

## Brand position

**Product:** MoonWitness ORM  
**Category:** Modular relational engine for Rust  
**Tagline:** Beyond Data. Witness Every Relation.  
**Technical promise:** A dependable relational core with a typed module kernel and independently evolving add-ons.

## Brand narrative

MoonWitness is built around the idea that modern software is not a collection of isolated records or a monolith of inseparable features. It is a connected system of domains, relationships, and capabilities.

The MoonWitness architecture brings those parts together through a stable relational core, explicit module contracts, and add-ons that can evolve independently.

“Moon” is a visual metaphor for perspective, cycles, and continuity. “Witness” represents visibility: understanding relationships, module dependencies, lifecycle transitions, and the data operations that shape an application. This is a brand interpretation, not a claim about historical word origin.

## Messaging hierarchy

1. **Primary:** A modular relational engine for Rust.
2. **Secondary:** Compose applications from a dependable ORM core, typed modules, and optional add-ons.
3. **Proof direction:** Explicit dependency graphs, deterministic lifecycle, migration ownership, and observable extension contracts — once implemented and validated.

Avoid describing planned capabilities as shipped features.

## Relationship to the MW-BAAS ecosystem

MoonWitness is positioned as infrastructure beneath MW-BAAS, not as a competing application platform. Its brand should communicate a dependable, reusable foundation: MW-BAAS may be its flagship consumer, but the ORM remains independently valuable to the wider Rust ecosystem. Keep the boundary visible in product copy, crate dependencies, documentation, and release planning.

## Visual identity direction

- Deep midnight navy: `#101827`
- Engineering blue: `#263B56`
- Lunar silver: `#C4D0DD`
- Mist white: `#E9EDF2`
- Optional accent: restrained lunar cyan, used sparingly.

## Logo concept

A minimal lunar eclipse or crescent enclosing a connected node graph:
- outer lunar arc: continuity and evolution;
- connected nodes: entities and relations;
- modular segments: independently composed add-ons;
- clean geometry: engineering precision.

Avoid a literal moon illustration that looks like a space or astronomy product. The mark should work as a small GitHub avatar, crate icon, and documentation mark.
